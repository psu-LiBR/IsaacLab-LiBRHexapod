Switch penalty comparison · 5×–100×

Purpose: simulation candidates for Jackson's real-robot comparison.

Hard filter: every leg ≤4 high-level command switches in every complete 1-second cycle, zero falls, zero torso contact, valid forward evaluation. Ranking within each algorithm shows three representative model files; it is not a deployment clearance.

Two waves: Wave 1 scales only the original switch term. Wave 2 uses the same original weight plus Jackson's new switch term. Every card shows both coefficients.

Tested multipliers: 5×, 10×, 30× and 100× (four discrete settings).

Coefficient reference: the original-term multiplier reference is −0.005, giving weights −0.025, −0.05, −0.15 and −0.5. Wave 1 has new λ = 0. Wave 2 uses the new-term reference λ = 0.0004 with the same multiplier, giving λ = 0.002, 0.004, 0.012 and 0.04. These are multiplier references, not a claim about every family's historical default.

Reproduction: use the matching .pt file, metric JSON and SHA256 in candidate_manifest.json. The attached model file is a training policy artifact; hardware testing still requires Jackson's control-stack validation.
